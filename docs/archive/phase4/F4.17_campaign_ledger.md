## Why this campaign exists

"A discard" is currently an inconsistent concept: depending on HOW a card is discarded, a
different incomplete subset of {catcher, recycling, ship, stamp effects, bookkeeping} fires.
Design principle (Robert): **all discards are equal** — every discard, from any source, fires
the same complete set. F4.17 routes every discard site through one canonical
`_discardCard(card, source)` / `_discardCards(cards, source)` method.

**Recon corrected a stale premise:** the OVERHAUL_PLAN's F4.17 entry claimed hex_51 reveal-miss
bypasses the discard effects. In CURRENT code it does NOT — reveal-miss already routes through
`_handleFieldDiscard` and fires the full set. (OVERHAUL_PLAN F4.17 entry needs this correction —
DESIGN_DOC_PATCHES / plan note.) The feared "TANGLED" risk does not exist. Verdict: **DRIFTED,
close to CLEAN.**

## Design decisions (locked — implement, don't re-litigate)

1. **`zodiac_ox` is a full discard.** It is the ONLY way to recover stranded field cards into
   hand: a stranded 3-stack you can't complete via deckflip, cleared by Ox, and **catcher
   rescues those cards to hand instead of losing them**. So Ox gains the full set including
   catcher — catcher-on-Ox is the key mechanic, not an oddity. Full inclusion.
2. **`game_catcher` stays a dedicated interception GATE** at the top of `_discardCard`, NOT an
   `onFieldDiscard` hook. Catcher decides WHETHER to discard (short-circuits before
   bookkeeping); recycling/ship REACT to a committed discard. Different semantics → don't mix.
   `onFieldDiscard` carries only post-commit side-effects (recycling, ship). (If a 2nd
   interceptor ever appears, promote to a `{consumed}` hook then — YAGNI now.)
3. **Bookkeeping uniformity is a [FIX].** Consumable discards (Horse/Monkey/Ox) currently skip
   `_discardCount`/`_discardedThisTurn`, so `roundDiscardCount` under-counts. After unification
   all sites bump all counters. This changes a reported number — confirmed wanted.
4. **Catcher intercepting hex_51 reveal-miss: KEEP.** Status quo; consistent with all-equal.
5. **Unify the two recycling ki reasons** (`recycling_discard` / `recycling_overflow`) → one.
6. **Out of scope (filed as observations, NOT this campaign):** duplicated `game_catcher`
   state-init in RunManager; stamp `fireDraw` lacking a hand-cap check (revisit with the
   Blessings hand-cap pass). `sym_osprey` (draw-layer interception, never reaches a discard)
   and `zodiac_dog` (un-discard / pulls from pile) are NOT discard sites — out of scope.

## `onFieldDiscard` hook

Signature (consistent with `onCaptureComplete`/`onRoundEnd`/`onBank`/`onPushFailure`):
```js
onFieldDiscard({ card, source, spirit, spirits, run, roundManager })
```
Fired once per discarded card, per equipped spirit, from inside `_discardCard` AFTER the
catcher gate + bookkeeping, BEFORE stamp dispatch. Side-effect style (no return value needed).
`econ_recycling` (+5·stacks ki) and `engine_ship` (`cardsDiscarded`++) implement it. `source`
is passed for completeness; neither branches on it (uniform — the point).

## Target shape

```js
// Batch convenience — loops _discardCard. Call sites that discard sets (Horse/Monkey/Ox) use this.
_discardCards(cards, source) { for (const c of cards) this._discardCard(c, source); }

_discardCard(card, source) {
  // source: 'deck_overflow' | 'hand_overflow' | 'consumable' | 'reveal_miss'
  // 1. Catcher GATE — may consume the card (→ hand) and short-circuit.
  if (this._tryCatcherIntercept(card)) return 'catcher';
  // 2. Bookkeeping (uniform for all sources).
  this._discardedThisTurn.push(card);
  this._allDiscards.push(card);
  this._discardCount++;
  // 3. onFieldDiscard side-effect hooks (recycling, ship).
  this._fireFieldDiscardHooks(card, source);
  // 4. Stamp discard-trigger effects.
  this._dispatchStampDiscardEffects(card);
  return 'field_discard';
}
```
Note: the empty-hand round-end check stays with the CALLER (consumables call
`_checkRoundEndOnEmptyHand()` after the batch; overflow paths don't empty the hand).
Horse's "clear hand BEFORE stamp draws" ordering is preserved by removing cards from hand at
the call site, then passing them to `_discardCards`.
